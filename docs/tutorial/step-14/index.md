Помимо JSX, `vue-jsx-vapor` также предоставляет функцию `h` для ручного создания узлов Vapor. Такой стиль обычно называют HyperScript. Он полезен, когда требуется более тонкий контроль над созданием узлов.

## Использование

Функция `h()` в Vapor похожа на `h()` для Virtual DOM, однако если вы передаёте аргумент `children`, то должны явно указать и аргумент `props`.

```tsx
h(type, props?, children?)
```

Например, следующий код создаёт простой элемент `div`:

```tsx
import { h } from 'vue-jsx-vapor'
export default () => h('div', null, 'hello')
```

## Реактивные значения необходимо оборачивать в функции

В режиме Vapor при передаче реактивных значений их, как правило, необходимо оборачивать в функции, чтобы среда выполнения могла отслеживать их изменения.

### Динамический компонент

Для динамических компонентов используйте функцию, возвращающую текущий компонент:

```tsx
h(Fragment, null, [() => h('El' + props.type)])
```

### Динамические пропсы

Для динамических пропсов также необходимо передавать функцию:

```tsx
h('div', { id: () => props.id })
```

### Объединение пропсов

Если нужно объединить несколько объектов пропсов, можно передать массив в `$:`, обернув каждый объект в функцию.

```tsx
h('div', { $: [() => ({ id: props.id }), () => attrs] })
```

### Проп `ref`

Проп `ref` поддерживает как реактивные переменные, так и функции обратного вызова (колбэки).

```tsx
const divRef = shallowRef()
h('div', { ref: divRef })
h('div', { ref: (el) => (divRef.value = el) })
```

## `children`

Аргумент `children` может содержать как один дочерний узел, так и массив дочерних узлов:

```tsx
h('div', null, 'hello')
h('div', null, ['hello', () => world])
```

### Слот по умолчанию

Слот по умолчанию можно передать непосредственно в виде функции:

```tsx
h(Comp, null, (slotProps) => ['hello', () => slotProps.foo])
```

### Несколько слотов

Для передачи нескольких слотов необходимо использовать объект:

```tsx
h(Comp, null, {
  default: (slotProps) => ['hello', () => slotProps.foo],
  other: () => 'other slot',
})
```

## Зачем оборачивать значения в функции?

В режиме Vapor аргументы, передаваемые в `h()`, не преобразуются автоматически в реактивные выражения, как это происходит в шаблонах или JSX. Если значение обёрнуто в функцию, среда выполнения сможет повторно вычислять его при необходимости и корректно отслеживать зависимости.

Это можно представить так:

- Статические значения — передавайте напрямую.
- Динамические значения — передавайте в виде функций.

## Когда следует использовать `h()`?

Функция `h()` полезна в следующих случаях:

- когда требуется вручную управлять созданием узлов;
- при написании низкоуровневой логики среды выполнения;
- когда необходимо динамически создавать компоненты, пропсы или слоты.

## Отличия от JSX

В JSX многие выражения автоматически преобразуются компилятором. При использовании `h()` нужно явно указывать, какие значения являются динамическими.

Например, следующие два варианта выражают одну и ту же идею:

```tsx
<>{<DynamicComponent.value />}</>
```

```tsx
h(Fragment, null, [() => h(DynamicComponent.value)])
```
